A 4 KB Python chess engine: a forced mate book found by trap-beam search against the house gauntlet, with a small fixed-depth alpha-beta fallback for lines the book does not cover. Practice trial-0: 6/6 checkmate, 141 plies, spare 1059.

`main_src.py` is the readable source of the packed entry `main.py` (packed with the official kit's `makefun compress`).

## Run it

```sh
MAKEFUN_ENV_URL=http://localhost:8080 python3 main.py
```
